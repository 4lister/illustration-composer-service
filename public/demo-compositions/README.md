# Примеры собранных композиций

## Пример 1: Финансы (Orange Palette)
**Метафора:** Репортаж монетка папка финансов оплата  
**Компоненты:** реч, монета, папка, чип, лампа  
**Палитра:** Orange  
**Формат:** Квадрат (1000x1000)

---

## Пример 2: Музыка (Teal Palette)
**Метафора:** Наушники музыка телефон подкаст  
**Компоненты:** наушники, лампа, чип, блок, coin  
**Палитра:** Teal  
**Формат:** Широкий (1200x630)

---

## Пример 3: Учёба (Purple Palette)
**Метафора:** Книга лампа ручка учёба идеи  
**Компоненты:** книга, лампа, ручка, блок, вазе  
**Палитра:** Purple  
**Формат:** Высокий (630x1200)

---

## Пример 4: Имена (Ручной подбор)
**Имя-исходник:** телефон, пазлы, кошелек  
**Компоненты:** найдены по имени  
**Палитра:** Purple  
**Формат:** Квадрат (1000x1000)
