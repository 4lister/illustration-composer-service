# 🎨 Конструктор Иллюстраций (Illustration Composer)

Многослойный сервис для создания SVG-иллюстраций с интеллектуальной композицией объектов по метафоре и автоматическим подбором декоративных элементов.

---

## ✨ Особенности

**Ключевые возможности:**
- 🧠 **Интеллектуальный подбор**: Автоматическое определение объектов по описаниям (метамфора, названия)
- 🎭 **Декоративные объекты**: 21 декоративный элемент с фильтрацией по списку `['vase', 'block', 'chip', 'lamp', 'folder']`  
- 🌈 **Цветовые палитры**: 3 готовые палитры (фиолетовая, оранжевая, бирюзовая) с экспортом
- 🔧 **Модульная архитектура**: SVG-библиотека отделена от бизнес-логики для лёгкого масштабирования

---

## 🚀 Быстрый старт

### Установка и запуск

```bash
npm install && npm run dev
```

Откройте `http://localhost:5173` в браузере.

### Сборка для продакшена

```bash
npm run build
```

Готовый код сжатых SVG-файлов находится в директории `dist/`.

## 📁 Архитектура проекта

Проект имеет модульную структуру: **SVG-библиотека** отделена от бизнес-логики. Легко масштабировать набор графических примитивов и логическое ядро — добавлять новые методы обработки или алгоритмы подбора объектов без изменения друг друга.

```
illustration-constructor/
├── index.html                 # Главный HTML-файл
├── vite.config.ts            # Конфигурация Vite для сборки и препроцессинга SVG
├── tsconfig.json             # Базовый конфиг TypeScript для всего проекта
├── package.json              # Зависимости и скрипты проекта
├── README.md                 # Документация (этот файл)
├── public/
│   ├── library/             # SVG-активы из библиотеки графических примитивов
│   │   ├── objects/          # Основные объекты (с ролью и размером)
│   │   └── backgrounds/      # Фон под палитры
│   └── ...                  # Дополнительные ресурсы
└── src/
    ├── main.tsx              # Точка входа приложения — компонент App с состоянием
    ├── components/           # React-компоненты (Canvas, Sidebar, etc.)
    ├── data/library.ts       # Конфигурация объектов SVG-библиотеки
    │   ├── FORMATS           # Наборы размеров для экспорта
    │   └── OBJECTS           # Описание объектов из библиотеки
    ├── lib/                  # Локальные утилиты (без внешних API)
    │   ├── compose.ts        # Методики композиции объектов в одну картинку
    │   ├── exportSvg.ts      # Генерация SVG и скачивание файла
    │   └── matchMetaphor.ts  # Алгоритмы подбора объектов по метафоре или именам
    └── types.ts              # Типы данных проекта
```

### Ключевые характеристики архитектуры

- **Модульность**: SVG-библиотека (`public/library/`) и бизнес-логика (`src/lib/`) отделены. Легко добавлять новые объекты, подходы к композиции или методы экспорта без изменения друг друга.

## 🌈 Настройки композиции и экспорта

### Форматы экспорта

| Формат | Описание | Использование |
|--------|----------|---------------|
| square | Квадратная область | Соцсети (Instagram) |
| vertical | Вертикальная область | Посты в вертикаль |
| wide | Горизонтальная область | Панели, баннеры |

### Цветовые палитры

- **`purple`**: Фиолетовая гамма с теплыми оттенками
- **`orange`**: Оранжевая палитра для энергичных иллюстраций  
- **`teal`**: Бирюзовая комбинация для современных дизайнов

Каждая палитра включает основные и акцентные цвета, а также фоновые оттенки и текст на фоне.

### Размеры объектов

- **`L` (Large)**: Большие объекты — подходят в качестве фонового элемента или центрального объекта композиции
- **`S` (Small)**: Маленькие элементы — используются для дополнительных деталей

## 🔧 Использование API / модулей

### Пример: Создать композицию по метафоре

```typescript
const metaphor = 'музыкальный стартап ищет инвестиции'
const objs = matchMetaphor(metaphor, 5) // maxObjects=5
const items = composeObjects(objs, formatId, { includeBackground: true })
downloadSvg(buildExportSvg(items, format), 'investiture.svg')
```

### Пример: Создать композицию по именам

```typescript
const names = 'книга, наушники, лампа'
const objs = matchNames(names) // Поиск объектов с данными именами
const items = composeObjects(objs, formatId, { includeBackground: true })
```

## 🐛 Troubleshooting

| Проблема | Решение |
|----------|---------|
| Ошибка импорта SVG | Проверьте `public/library/objects/` на наличие корректных путей |
| Отсутствие объектов по метафоре | Попробуйте более простые слова или добавьте новые в `src/data/library.ts` |
| Все объекты отображаются в декоративном слоте | Убедитесь, что фильтр использует `includes` против списка `['vase', 'block', 'chip', 'lamp', 'folder']` |
| Неверные цвета | Убедитесь, что палитра выбрана корректно при экспорте |
| Ошибка TypeScript | Перезапустите компиляцию через `npm run dev` или `npm run build` |
